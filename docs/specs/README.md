# Specs

This folder logs the work for the **Agentic Assets Manager** extension — what's been built and
what's planned — so the project's intent stays tracked as it grows.

## Status legend

- 🟢 **Done** — implemented and verified.
- 🟡 **In progress** — actively being built.
- ⚪ **Planned** — agreed, not started.

## Conventions

- One spec per file, numbered `NNNN-short-title.md`.
- Each spec records: goal, scope (in/out), design, acceptance check, and status.
- Update the status here and in the spec file as work moves forward.
